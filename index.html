Configuration requise (une seule fois)

Cet outil est hébergé en dehors de Claude (GitHub / fichier statique), il a donc besoin d'une petite base de données gratuite pour que les 9 secteurs partagent leurs données. Firebase (Google) fait ça très bien et gratuitement. À faire une seule fois, par toi seul — les 9 contributeurs n'auront besoin d'aucun compte.

  1. Va sur console.firebase.google.com, connecte-toi avec un compte Google, clique "Ajouter un projet" et donne-lui un nom (ex: echos-zs-daa). Désactive Google Analytics si proposé (pas nécessaire).
  2. Dans le menu de gauche du projet, ouvre Build → Firestore Database, clique "Créer une base de données", choisis une région proche, puis "Mode production".
  3. Une fois créée, va dans l'onglet "Règles" de Firestore et remplace le contenu par : 
    rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /echos_kv/{doc} {
      allow read, write: if true;
    }
  }
}
    puis clique Publier. (Cela rend les données ouvertes à quiconque a le lien — cohérent avec le principe "pas de compte" ; ne mets pas d'informations confidentielles sensibles.)
  4. Retourne à la racine du projet (icône ⚙️ → Paramètres du projet), descends à "Vos applications", clique l'icône </> (Web), donne un surnom, clique "Enregistrer l'application". Firebase affiche un bloc firebaseConfig = {'{'} apiKey: ..., projectId: ... {'}'} : copie ces 6 valeurs ci-dessous.

Ce code protègera l'onglet "Calendrier (Admin)". Retiens-le : lui seul permettra d'y accéder ensuite. Il ne sera jamais demandé aux 9 contributeurs.

Cette configuration est enregistrée directement dans le fichier HTML sur ton ordinateur (bouton ci-dessous) — tu n'auras à le faire qu'une seule fois, avant de mettre le fichier en ligne sur GitHub Pages.
